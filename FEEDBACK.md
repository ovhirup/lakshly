# Feedback & feature requests: built with you 💛

Thank you for taking the time. Every idea is read by a human.

## How it works

1. **Tell us:** in the app (*More → Feedback & Feature Requests*, coming in Phase 1), or for now via [GitHub Issues](../../issues/new/choose): 🐞 Bug report or ✨ Feature request.
2. **Instant thank-you:** every request is acknowledged right away and gets a visible status:
   `Received` → `Planned` → `In progress` → `Shipped` (or `Not now`, always with a reason).
3. **Human reply targets:**
   - ⭐ **Premium members:** within **1 business day (IST)**; data, security or billing issues the **same day**.
   - Free: within **5 business days** (best effort).
4. **Premium priority:** Premium requests carry the `premium-priority` label, are triaged first, and their votes count 3×. Premium members get early access to features they asked for.
5. **Credit where it's due:** when your request ships, we thank you by name (opt-in) in the **Built with you** section of [CHANGELOG.md](CHANGELOG.md).

Privacy: never include real account numbers, statements or amounts in feedback. Screenshots must be redacted, or use demo data.
